# معماری و مراحل

- Frappe 16 و اپ saeenaria_portal؛ بدون ERPNext.
- MariaDB 11.8 مستقل؛ Redis مستقل برای cache و queue؛ volume پایدار جدا از سرویس‌های فعلی.
- توسعه روی Windows با Linux containers؛ بسته تولید بعداً با وب، worker، scheduler و websocket مستقل آماده خواهد شد.
- سه حوزه و تخصیص چندگانه مسئول؛ دسترسی رکورد در سرور بر مبنای تخصیص حوزه.
- داده استاندارد Date در پایگاه؛ ورودی و نمایش شمسی در رابط فارسی.
- مسیر نخست: اقدام کاری، ثبت مسئول/موعد/نتیجه و گزارش مدیر.
- مراحل بعدی: شاخص و دوره، گزارش و تصمیم، تقویم و تکرار، واردکردن CSV، آزمون دسترسی و استقرار.

تنظیمات ناشناختهٔ رسوب، مشتری راکد و انتساب فروش پیش‌فرض ساختگی نخواهند داشت.
فایل compose.dev.yaml مخصوص توسعه است و روی سرور واقعی استفاده نمی‌شود.
