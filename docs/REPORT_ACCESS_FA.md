# دسترسی موقت گزارش‌ها و ورود اطلاعات

مدیر سامانه در `/portal-account#report-access` می‌تواند «دسترسی مشاهده و ویرایش برای همه کاربران فعال» را روشن یا خاموش و ذخیره کند.

فعال‌بودن گزینه، مشاهده، خروجی و ورود اطلاعات فروش، خرید و موجودی و ویرایش کالاها را برای کاربران فعال واردشده فراهم می‌کند. مهمانان و کاربران غیرفعال مشمول نیستند. مدیریت کاربران، رمزها، تنظیمات اتصال و مجوزهای مدیریتی همچنان محدود است.

برای لغو، تیک را بردارید و ذخیره کنید. دسترسی موقت در درخواست بعدی لغو می‌شود؛ مجوزهای اصلی مدیران و مسئولان باقی می‌ماند و اطلاعات ثبت‌شده حذف نمی‌شود. این تنظیم برای هر سایت مستقل است؛ روی سرور و نسخه محلی جداگانه تغییر دهید.

وضعیت در Single DocType «Portal Report Access» ذخیره و تغییرات آن ثبت می‌شود. مقدار پیش‌فرض نصب جدید خاموش است. داده و وضعیت فعال‌بودن به Git منتقل نمی‌شوند.
