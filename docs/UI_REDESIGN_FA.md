# بازطراحی رابط پورتال — ۲۰ اکتبر ۲۰۲۶

نسخه قابل بررسی: http://portal.localhost:8085/portal

ناوبری مشترک با لینک مستقیم، نشانگر صفحه جاری، تب‌های بخش عملکرد، فیلترهای آشکار، مسیر ثبت مقدار شاخص و گزارش در بخش مرتبط، و طراحی مشترک فرم‌ها، جدول‌ها و صفحات اضافه شده است. لینک‌های خرید و مدیریت بر اساس پاسخ مجاز سرور نمایش داده می‌شوند. محیط فنی Frappe همچنان از میزکار مدیریت در دسترس است.

این تغییرات در لایه HTML/CSS/JavaScript هستند؛ داده‌ها و قواعد تأیید یا دسترسی تغییر نمی‌کنند. راهنمای طراحی، WCAG 2.2 برای پیمایش یکسان، فوکوس واضح، صفحه‌کلید و اندازه کنترل‌ها بوده است؛ این به معنی تأیید رسمی انطباق کامل نیست.

## بازگشت با یک دستور

از پوشه اصلی پروژه اجرا کنید:

```powershell
python docker/rollback-portal-ui.py --apply
```

سپس در مرورگر `Ctrl+F5` بزنید. بررسی امکان بازگشت بدون اعمال تغییر:

```powershell
python docker/rollback-portal-ui.py --check
```

نسخه دقیق فایل‌ها پیش از این بازطراحی در `.local/ui-redesign-20261020` نگهداری شده است، از جمله فایل‌هایی که از قبل تغییرات ثبت‌نشده داشتند و صفحات خرید و موجودی که هنوز در Git نبودند. این پوشه محلی و خارج از Git است؛ برای انتقال به رایانه دیگر باید آن را همراه پروژه نگه دارید. بازگردانی به `git reset` نیاز ندارد.

اسکریپت پیش از هر تغییری، تمام نسخه‌های پشتیبان و هش فایل‌های فعلی را بررسی می‌کند. اگر بعداً همان فایل‌ها ویرایش شده باشند، بدون تغییر هیچ فایل متوقف می‌شود تا کار جدید بازنویسی نشود. اجرای دوباره پس از بازگشت بی‌اثر است. فایل راهنما و ابزار بازگشت برای سابقه باقی می‌مانند.

## بررسی

نحو سه فایل JavaScript بررسی شد. در پورتال محلی، نمایش واقعی صفحات و داده‌ها، جابه‌جایی تب‌ها با صفحه‌کلید، باقی‌ماندن مسیر ثبت شاخص و گزارش، پنهان‌شدن فیلترهای نامرتبط در فرم ثبت کار و ناوبری صفحات مرخصی و موجودی بررسی شد. هیچ فرم عملیاتی برای آزمون ثبت نشده است. ابزار بازگشت در یک نسخه موقت مستقل، از جمله حفظ تغییرات قبلی، تشخیص تعارض و اجرای دوباره بررسی شده است.
